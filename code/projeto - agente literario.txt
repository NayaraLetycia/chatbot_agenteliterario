TEMA 1 - Sistema de recomendação personalizado para compra de livros.
Os alunos deverão desenvolver um assistente inteligente integrado com LLMs que seja
capaz de manter um diálogo com o usuário para entender seus gostos, aptidões e
interesses para efetuar recomendações personalizadas e elaborar planos de leitura.
(peso 9)
O diferencial é conseguir estruturar chamadas de API para compra de livros à partir do
processamento de linguagem natural.
(peso 1)

Exercícios
Exercício 1: Análise de Sentimentos
Objetivo:
Utilizar a API de LLM para analisar e classificar os sentimentos expressos em uma frase ou
texto, retornando a polaridade (positivo, neutro, negativo) e o score.
Tarefa:
1) Utilizar a API de LLM para processar um texto e classificar o sentimento nele expresso.
2) Desenvolver um script Python que leia uma frase ou texto e retorne à classificação do
sentimento e o score correspondente.
Exercício 2: Identificação de Entidades
Objetivo:
Utilizar a API de LLM para identificar e classificar entidades nomeadas em um texto (por
exemplo, pessoas, organizações, lugares).
Tarefa:
1)Utilizar a API de LLM para identificar entidades mencionadas no texto.
2)Desenvolver um script Python que leia um texto e retorne as entidades encontradas e
suas classificações.
Exercício 3: Geração de Texto
Objetivo:
Utilizar a API de LLM para gerar texto a partir de um prompt fornecido.
Tarefa:
1)Utilizar a API de LLM para gerar um texto com base em um prompt inicial.
2)Desenvolver um script Python que leia um prompt e retorne o texto gerado pelo modelo.
Exercício 4: Resolução de Problemas
Objetivo:
Utilizar a API de LLM para resolver um problema a partir de uma pergunta ou questão
fornecida.
Tarefa:
1)Utilizar a API de LLM para responder a uma pergunta ou resolver um problema específico.
2)Desenvolver um script Python que leia uma pergunta e retorne a resposta ou solução.
Exercício 5: Conversa com um Agente Virtual
Objetivo: Utilizar a API de LLM para criar uma conversa com um agente virtual, baseado
nas entradas fornecidas pelo usuário.
Tarefa:
1) Utilizar a API de LLM para interagir com o usuário em uma conversa.
2)Desenvolver um script Python que leia entradas do usuário e retorne respostas do agente
virtual.
