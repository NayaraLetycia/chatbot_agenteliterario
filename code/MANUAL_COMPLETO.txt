1. VISÃO GERAL DO PROJETO
================================================================================

O Agente Literário Inteligente é um assistente virtual que usa Inteligência
Artificial (LLM) para recomendar livros de forma personalizada através de
conversas naturais com o usuário.

OBJETIVO PRINCIPAL (PESO 9):
- Manter diálogo natural com o usuário
- Entender gostos, aptidões e interesses literários
- Efetuar recomendações personalizadas
- Elaborar planos de leitura progressivos

DIFERENCIAL TÉCNICO (PESO 1):
- Estruturar chamadas de API para compra de livros
- Processar linguagem natural para buscar automaticamente
- Gerar links diretos de compra

TECNOLOGIAS:
- Python 3.10+
- Groq API (LLM Llama 3 - gratuito)
- Google Books API (busca de livros - gratuita)
- Streamlit (interface web - gratuito)

3. COMO INSTALAR
================================================================================

PASSO 1: Instalar Python
-------------------------
- Certifique-se que tem Python 3.10 ou superior
- Verificar: python --version

PASSO 2: Instalar Dependências
-------------------------------
No terminal, na pasta do projeto:

    pip install -r requirements.txt

Isso instalará:
- groq (LLM Llama 3)
- python-dotenv (gerenciar variáveis)
- requests (HTTP para APIs)
- streamlit (interface web)
- httpx (cliente HTTP)

PASSO 3: Obter API Key Gratuita
--------------------------------
1. Acesse: https://console.groq.com
2. Crie conta gratuita (pode usar Google/GitHub)
3. Vá em "API Keys" → "Create API Key"
4. Copie a chave gerada

PASSO 4: Configurar API Key
----------------------------
Crie arquivo ".env" na raiz do projeto com:

    GROQ_API_KEY=gsk_sua_chave_aqui

PASSO 5: Testar Instalação
---------------------------
Execute:

    python testar_instalacao.py

Se tudo aparecer ✓ verde, está pronto!

4. COMO USAR - VERSÃO TERMINAL
================================================================================

INICIAR:
--------
    python agente_literario.py

COMANDOS DISPONÍVEIS:
---------------------

1. Conversa Normal
   Digite naturalmente suas preferências:
   Exemplo: "Gosto de fantasia medieval"

2. Buscar Livros (comando especial)
   Formato: buscar: [termo]
   Exemplo: buscar: Harry Potter
   
   Retorna:
   - Lista de livros encontrados
   - Autores
   - Links para compra

3. Gerar Plano de Leitura (comando especial)
   Digite: plano
   
   Gera:
   - 5 livros recomendados
   - Ordem progressiva (fácil → difícil)
   - Justificativa para cada livro

4. Sair
   Digite: sair

FLUXO DE USO TÍPICO:
--------------------
1. Agente faz pergunta inicial sobre seus gostos
2. Você responde (ex: "Gosto de mistério")
3. Agente aprofunda (ex: "Prefere policial ou suspense?")
4. Você especifica (ex: "Suspense psicológico")
5. Agente recomenda livros específicos
6. Links de compra aparecem automaticamente
7. Você pode pedir plano completo digitando: plano

EXEMPLO DE SESSÃO:
------------------
🤖 Agente: Olá! Para começar, você gosta mais de ficção ou não-ficção?
👤 Você: Ficção
🤖 Agente: Ótimo! Que tipo de ficção te atrai mais?
👤 Você: Ficção científica, mas não muito técnica
🤖 Agente: RECOMENDAÇÃO: O Guia do Mochileiro das Galáxias por Douglas Adams
📖 Buscando links de compra...
🔗 Onde comprar:
   • Link 1 - https://books.google.com/...
   • Link 2 - https://books.google.com/...

6. FUNCIONALIDADES PRINCIPAIS
================================================================================

FUNCIONALIDADE 1: CONVERSA CONTEXTUALIZADA
-------------------------------------------
DESCRIÇÃO:
O agente mantém memória de toda conversa, lembrando preferências mencionadas
anteriormente.

COMO FUNCIONA:
- Histórico armazenado em lista
- Cada mensagem enviada ao LLM com contexto completo
- Agente lembra de detalhes específicos
- Refina recomendações progressivamente

EXEMPLO:
  Turno 1:
    Você: "Gosto de fantasia"
  Turno 5:
    Agente: "Como você gosta de fantasia, recomendo..."
    (lembrou da preferência do turno 1)

BENEFÍCIO:
Conversa natural, sem repetições, como falar com um bibliotecário real.

---

FUNCIONALIDADE 2: ANÁLISE DE PREFERÊNCIAS
------------------------------------------
DESCRIÇÃO:
Sistema extrai automaticamente seus gostos através da conversa.

O QUE É ANALISADO:
- Gêneros literários favoritos
- Autores já lidos e apreciados
- Temas de interesse específicos
- Nível de complexidade desejado
- Preferências emocionais (alegre, tenso, reflexivo)

COMO FUNCIONA:
- LLM processa linguagem natural
- Identifica padrões nas respostas
- Constrói perfil dinâmico
- Usa perfil para filtrar recomendações

EXEMPLO:
  Você diz: "Li Harry Potter quando criança, agora quero algo mais adulto"
  
  Sistema identifica:
  - Gênero: Fantasia
  - Autor conhecido: J.K. Rowling
  - Nível: Busca algo mais maduro
  - Progressão: Do jovem ao adulto

---

FUNCIONALIDADE 3: RECOMENDAÇÕES PERSONALIZADAS
-----------------------------------------------
DESCRIÇÃO:
Sugere livros ESPECÍFICOS (não genéricos) baseado no perfil construído.

CARACTERÍSTICAS:
- Livros reais com títulos e autores
- Justificativa para cada recomendação
- Considera múltiplos fatores do perfil
- Adapta com feedback do usuário

EXEMPLO DE RECOMENDAÇÃO:
  RECOMENDAÇÃO: O Nome do Vento por Patrick Rothfuss
  
  JUSTIFICATIVA:
  - Fantasia medieval complexa (gostou de Tolkien)
  - Sistema de magia detalhado (interesse declarado)
  - Estilo maduro (pediu complexidade)
  - Primeira parte de série (gosta de sagas)

DIFERENCIAL:
Não apenas gênero, mas livros específicos que combinam MÚLTIPLOS aspectos.

---

FUNCIONALIDADE 4: PLANOS DE LEITURA PROGRESSIVOS
-------------------------------------------------
DESCRIÇÃO:
Cria roteiro de 5 livros do mais acessível ao mais desafiador.

ESTRUTURA:
1. Livro introdutório (fácil entrada no tema)
2. Livro intermediário (aprofunda conceitos)
3. Livro padrão (representativo do gênero)
4. Livro avançado (maior complexidade)
5. Livro desafiador (obra-prima complexa)

EXEMPLO - FICÇÃO CIENTÍFICA:
  1. O Guia do Mochileiro das Galáxias - Douglas Adams
     (Introdução leve e humorística)
  
  2. Eu, Robô - Isaac Asimov
     (Conceitos clássicos, contos curtos)
  
  3. Fundação - Isaac Asimov
     (Narrativa épica, múltiplos personagens)
  
  4. Neuromancer - William Gibson
     (Cyberpunk denso, linguagem complexa)
  
  5. Solaris - Stanisław Lem
     (Filosófico, conceitos abstratos)

BENEFÍCIO:
Evita frustração de começar por livro muito difícil ou entediar com muito fácil.

---

FUNCIONALIDADE 5: BUSCA E COMPRA (API GOOGLE BOOKS)
----------------------------------------------------
DESCRIÇÃO:
Integração automática para encontrar livros e gerar links de compra.

PROCESSAMENTO NLP:
1. Agente faz recomendação em texto natural
2. Sistema extrai padrão "RECOMENDAÇÃO: [Título] por [Autor]"
3. Monta query de busca
4. Chama Google Books API
5. Retorna resultados com links

INFORMAÇÕES RETORNADAS:
- Título completo
- Autor(es)
- Descrição/sinopse
- Link para Google Books (compra/preview)
- Imagem da capa (quando disponível)

EXEMPLO DE BUSCA:
  INPUT: "Harry Potter e a Pedra Filosofal"
  
  OUTPUT:
  1. Harry Potter e a Pedra Filosofal
     Autor: J.K. Rowling
     Link: https://books.google.com.br/books?id=...
     
  2. Harry Potter e a Câmara Secreta
     Autor: J.K. Rowling
     Link: https://books.google.com.br/books?id=...

MODO MANUAL:
Na versão web, pode buscar diretamente na sidebar sem conversar.

8. DIFERENCIAL TÉCNICO (API DE COMPRA)
================================================================================

REQUISITO (PESO 1):
"Estruturar chamadas de API para compra de livros a partir do processamento
de linguagem natural"

COMO IMPLEMENTAMOS:
-------------------

ETAPA 1: PROCESSAMENTO DE LINGUAGEM NATURAL
O agente conversa naturalmente e faz recomendações em texto livre:
  "RECOMENDAÇÃO: O Nome do Vento por Patrick Rothfuss"

ETAPA 2: EXTRAÇÃO DE INFORMAÇÕES
Sistema analisa a resposta do LLM e extrai:
  - Título: "O Nome do Vento"
  - Autor: "Patrick Rothfuss"

ETAPA 3: MONTAGEM DA QUERY
Cria query de busca otimizada:
  "O Nome do Vento Patrick Rothfuss"

ETAPA 4: CHAMADA À API
```python
def buscar_livros_google(self, query, max_results=5):
    url = "https://www.googleapis.com/books/v1/volumes"
    params = {
        "q": query,              # Busca
        "maxResults": max_results,  # Limite
        "langRestrict": "pt",    # Prioriza português
        "orderBy": "relevance"   # Mais relevantes
    }
    response = requests.get(url, params=params, timeout=10)
    return response.json()
```

ETAPA 5: PROCESSAMENTO DA RESPOSTA
Extrai informações relevantes:
  - Título
  - Autores
  - Descrição
  - Link de compra (infoLink)
  - Imagem da capa

ETAPA 6: APRESENTAÇÃO AO USUÁRIO
Formata e exibe links clicáveis.

DIFERENCIAL:
------------
✓ AUTOMÁTICO: Não precisa buscar manualmente
✓ INTELIGENTE: Extrai do contexto da conversa
✓ INTEGRADO: Recomendação + compra em um fluxo
✓ PRÁTICO: Links diretos, não apenas nomes de livros

EXEMPLO COMPLETO:
-----------------
CONVERSA:
  Você: "Gosto de fantasia épica"
  Agente: "RECOMENDAÇÃO: A Guerra dos Tronos por George R.R. Martin"

PROCESSAMENTO AUTOMÁTICO:
  [NLP] Detecta padrão de recomendação
  [API] Busca "A Guerra dos Tronos George R.R. Martin"
  [RETORNO] 
    • A Guerra dos Tronos - Link: https://books.google.com/...
    • Boxe Game of Thrones - Link: https://books.google.com/...
    • A Fúria dos Reis - Link: https://books.google.com/...

RESULTADO:
Usuário vai direto do conselho à compra!

9. ARQUITETURA DO SISTEMA
================================================================================

VISÃO GERAL:
------------
```
[USUÁRIO]
    ↓ (texto natural)
[INTERFACE - Streamlit ou Terminal]
    ↓ (mensagem)
[AGENTE LITERÁRIO]
    ↓ (histórico + mensagem)
[LLM - Groq/Llama 3]
    ↓ (resposta)
[PROCESSADOR DE RECOMENDAÇÕES]
    ↓ (extração de livros)
[GOOGLE BOOKS API]
    ↓ (resultados)
[USUÁRIO] ← (recomendação + links)
```

COMPONENTES:
------------

1. INTERFACE (app_web.py / agente_literario.py)
   - Captura entrada do usuário
   - Exibe respostas
   - Gerencia interação

2. CLASSE AgenteLiterario
   - Mantém estado da conversa
   - Gerencia histórico
   - Coordena fluxo

3. GROQ CLIENT (LLM)
   - Processa linguagem natural
   - Gera respostas contextualizadas
   - Modelo: Llama 3.1 70B

4. GOOGLE BOOKS API
   - Busca livros
   - Retorna metadados
   - Fornece links

5. GERENCIADOR DE PERFIL
   - Armazena preferências
   - Atualiza dinamicamente
   - Usado para refinar recomendações

FLUXO DE DADOS:
---------------

CONVERSA NORMAL:
1. Usuário digita mensagem
2. Mensagem adicionada ao histórico
3. Histórico completo enviado ao LLM
4. LLM gera resposta contextualizada
5. Resposta adicionada ao histórico
6. Exibido ao usuário

RECOMENDAÇÃO COM API:
1-5. (igual conversa normal)
6. Sistema detecta padrão "RECOMENDAÇÃO:"
7. Extrai título e autor
8. Monta query
9. Chama Google Books API
10. Processa resultados
11. Adiciona links à resposta
12. Exibe tudo ao usuário

PERSISTÊNCIA:
-------------
- Histórico: Em memória (session state no Streamlit)
- Configurações: Arquivo .env
- Sem banco de dados (simplicidade)

SEGURANÇA:
----------
- API keys em variáveis de ambiente
- Não armazena dados pessoais
- Sem autenticação (app local)

  Usuário: "Meu clube tem 8 pessoas com gostos variados. Preciso de algo
            que agrade a maioria"
  Agente: "Interessante! Me conte mais sobre o grupo"
  Usuário: "Metade gosta de ficção, metade prefere não-ficção. Idades
            entre 30-50 anos"
  Agente: "Para grupos diversos, recomendo:
           RECOMENDAÇÃO: Sapiens por Yuval Noah Harari
           Não-ficção, mas lê como romance. História da humanidade de
           forma acessível. Gera ótimas discussões. Sucesso em clubes
           de leitura mundialmente."

RESULTADO:
Livro que unifica grupo diverso e promove discussão.

11. PERGUNTAS FREQUENTES
================================================================================

P1: O sistema funciona offline?
--------------------------------
R: NÃO parcialmente. Precisa de internet para:
   - LLM (Groq API)
   - Busca de livros (Google Books API)
   
   O código roda local, mas as APIs são online.

P2: Quanto custa usar?
----------------------
R: TOTALMENTE GRATUITO!
   - Groq: Gratuito até 14.400 requisições/dia
   - Google Books: Gratuito sem limites
   - Streamlit: Gratuito (roda local)
   - Python: Gratuito e open-source

P3: Funciona em português?
---------------------------
R: SIM! 
   - LLM entende e responde em português
   - Google Books prioriza livros em português (langRestrict: "pt")
   - Interface toda em português

P4: Posso usar para outros idiomas?
------------------------------------
R: SIM! Basta conversar no idioma desejado.
   Para mudar idioma dos resultados da API:
   - Editar parâmetro langRestrict em buscar_livros_google()

P5: Como o agente lembra das conversas anteriores?
---------------------------------------------------
R: Mantém lista de mensagens (histórico) e envia tudo ao LLM a cada turno.
   Memória dura enquanto o programa está rodando.
   Fechar = perde histórico.

P6: Posso salvar as recomendações?
-----------------------------------
R: Atualmente não automaticamente. Você pode:
   - Copiar e colar do terminal
   - Screenshot da interface web
   - Adicionar função de export (melhoria futura)

P7: E se o livro recomendado não existir?
------------------------------------------
R: Raro porque:
   - LLM treinado em livros reais
   - API Google Books valida existência
   - Sistema mostra "Nenhum livro encontrado" se não achar

P8: Funciona para outros tipos de mídia?
-----------------------------------------
R: Foco é LIVROS, mas você pode adaptar:
   - Trocar Google Books por API de filmes/música
   - Ajustar prompts do LLM

P9: Preciso saber programar para usar?
---------------------------------------
R: NÃO! 
   - Versão web é totalmente visual
   - Instalação tem guia passo-a-passo
   - Uso é conversacional

P10: Posso contribuir com melhorias?
-------------------------------------
R: SIM! Projeto é educacional. Ideias:
   - Adicionar mais APIs (Amazon, Skoob)
   - Sistema de login e perfis salvos
   - Integração com e-mail (newsletter)
   - App mobile
   - Compartilhamento social

12. RESOLUÇÃO DE PROBLEMAS
================================================================================

PROBLEMA 1: "No module named 'groq'"
------------------------------------
CAUSA: Dependências não instaladas

SOLUÇÃO:
    pip install -r requirements.txt

Ou especificamente:
    pip install groq httpx python-dotenv requests streamlit

---

PROBLEMA 2: "API key not found"
--------------------------------
CAUSA: Arquivo .env não existe ou está incorreto

SOLUÇÃO:
1. Verificar se arquivo .env existe na raiz do projeto
2. Abrir .env e conferir formato:
   GROQ_API_KEY=gsk_sua_chave_aqui
   (SEM aspas, SEM espaços extras)
3. Se não tem chave, obter em: https://console.groq.com

---

PROBLEMA 3: Erro "TypeError: Client.__init__() got unexpected keyword"
-----------------------------------------------------------------------
CAUSA: Versão incompatível do groq/httpx

SOLUÇÃO:
    pip install --upgrade groq httpx

Versões necessárias:
    groq>=0.11.0
    httpx>=0.27.0

---

PROBLEMA 4: "Rate limit exceeded"
----------------------------------
CAUSA: Muitas requisições em pouco tempo

SOLUÇÃO:
- Aguardar 1 minuto
- Limite gratuito: 30 req/minuto, 14.400/dia
- Evitar enviar muitas mensagens rapidamente

---

PROBLEMA 5: Streamlit não abre no navegador
--------------------------------------------
CAUSA: Porta ocupada ou navegador não detectado

SOLUÇÃO:
1. Abrir manualmente: http://localhost:8501
2. Ou especificar porta:
   streamlit run app_web.py --server.port 8502

---

PROBLEMA 6: Google Books retorna resultados em inglês
------------------------------------------------------
CAUSA: Livros em português podem ter menos resultados

SOLUÇÃO:
- Normal para títulos muito específicos
- API prioriza português (langRestrict: "pt")
- Mas mostra inglês se não achar em português

---

PROBLEMA 7: Agente não lembra conversa anterior
------------------------------------------------
CAUSA: Histórico em memória, perdido ao fechar

SOLUÇÃO:
- Manter sessão aberta
- Não fechar aplicação entre conversas
- Para persistência: implementar banco de dados (melhoria futura)

---

PROBLEMA 8: Respostas muito lentas
-----------------------------------
CAUSA: Internet lenta ou servidor Groq sobrecarregado

SOLUÇÃO:
- Verificar conexão de internet
- Groq geralmente responde em 2-3 segundos
- Se persistir, tentar mais tarde

---

PROBLEMA 9: Recomendações genéricas
------------------------------------
CAUSA: Informações insuficientes do usuário

SOLUÇÃO:
- Dar mais detalhes nas respostas
- Responder perguntas do agente
- Mencionar livros/autores que já conhece

---

PROBLEMA 10: Erro ao buscar livros
-----------------------------------
CAUSA: Problema com Google Books API

SOLUÇÃO:
1. Verificar internet
2. API pode estar temporariamente indisponível
3. Tentar novamente em alguns minutos
4. Usar busca manual na sidebar (versão web)
